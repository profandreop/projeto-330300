# 🌳 Projeto 3-30-300 Manaus

## Acessibilidade e distribuição das áreas verdes:
### análise e visualização matemática em um bairro de Manaus-AM

Este projeto tem como objetivo analisar a distribuição e acessibilidade das áreas verdes urbanas no bairro Praça 14 de Janeiro, em Manaus-AM, utilizando a metodologia 3-30-300.

Além da análise ambiental, o projeto busca desenvolver visualizações matemáticas e objetos de aprendizagem digitais voltados ao ensino médio, promovendo educação ambiental, análise de dados e democratização da informação.

---

# 🎯 Objetivos

- Verificar o parâmetro “3” do método 3-30-300 através de entrevistas com moradores;
- Calcular a cobertura vegetal do bairro para análise do parâmetro “30”;
- Analisar a acessibilidade da população às áreas verdes públicas utilizando buffers de 300m;
- Visualizar dados ambientais através de gráficos e mapas interativos;
- Desenvolver materiais educativos e acessíveis para estudantes do ensino médio.
